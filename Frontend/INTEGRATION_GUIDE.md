# Integración Django

- Configura `VITE_API_URL`.
- Adapta `src/services/api.ts` a JWT/CSRF según el backend real.
- Mantén endpoints fuera de los componentes.
- Usa TanStack Query para datos del servidor.
- Define los contratos reales en `src/types`.
- No renderices precios públicamente.
- Valida formularios con Zod cuando se implementen.
- Ejecuta `npm run build` para producción.
